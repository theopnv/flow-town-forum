# Flow Town Forum

![Flow Town map](assets/social-world.png)

This is the public forum for [Flow Town](https://flowtown.theopnv.com), a map of the work behind software delivery. Use it to report problems, suggest changes, and ask questions about the content.

The Flow Town source code is private. This repository holds only the discussion.

## How to post

1. Open the [Issues](https://github.com/theopnv/flow-town-forum/issues) tab.
2. Search the open and closed issues first. Someone may have raised your point already. If so, add a comment or a 👍 reaction to it.
3. Click **New issue**.
4. Write a short title and describe your point. Add a label if one fits.

You need a GitHub account to post.

## What to post

| Label | Use it for |
| --- | --- |
| `bug` | Something on the site does not work or looks wrong. |
| `enhancement` | A new feature, topic, pain point, or capability. |
| `documentation` | An error, gap, or outdated statement in a topic or resource. |
| `accessibility` | A barrier for people who use a keyboard, a screen reader, or other assistive tools. |
| `question` | You want to know why the map shows something in a given way. |

## Write a good issue

- Link to the page. Copy the URL from your browser, because each topic and pain point has its own address.
- For a bug, tell us what you did, what you expected, and what happened. Add your browser and device. A screenshot helps.
- For a content change, give a source: a book, a paper, a talk, or your own experience on a team.
- Keep one subject per issue. Two ideas in one issue are hard to track and close.

## What happens next

I read each new issue and reply as soon as I can. I can accept a suggestion, ask for more details, or close it with an explanation. When a change goes live on the site, I close the issue and link to the update.

## Be kind

Be respectful to other people here. I delete spam, personal attacks, and off-topic posts.
